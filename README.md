# DealMatcher

A prototype e-commerce app that allows you to swipe through offers in a Tinder-like fashion.
Created with .NET Clean-Architecture pattern and template  (C#) for backend and Flutter for UI.

This project is being developed for the **"Software engineering 2"** course at the Faculty of Mathematics and Information Science (MiNI), Warsaw University of Technology.
